# LJT-Homepage

Personal academic homepage of Junteng Liu, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template and hosted on GitHub Pages.

## Content

- `_pages/about.md`: About page (personal details, education, research experience, publications, skills, contact)
- `_pages/publications.html`: Publications list
- `_publications/`: Publication entries
- `_config.yml`: Site-wide configuration
- `_data/navigation.yml`: Top navigation menu

## Running locally

1. Install ruby-dev, bundler, and nodejs.
1. Run `bundle install`.
1. Run `bundle exec jekyll serve -l -H localhost` and open http://localhost:4000.
